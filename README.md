# Task Management Application – QA Testing Assignment

## Overview

This repository contains my QA testing assignment for a Task Management Application.

The application includes:

* User Registration & Login
* Create Task
* View Task List
* Edit Task
* Delete Task
* Database-based task storage

## Testing Coverage

The assignment covers:

* Positive, negative, and edge test cases
* Registration testing
* Login testing
* Task CRUD testing
* Input validation
* Error handling
* Security considerations
* Data integrity

## Bug Identification

The assignment also identifies potential bugs and risk areas without executing the application, including:

* Authentication and authorization issues
* Data privacy risks
* Database and data persistence issues
* Input validation problems
* SQL injection risks
* Session management issues
* Error handling problems
